# 交大空教室查询 (大连交通大学)

基于大连交通大学综合教务管理系统(jw.djtu.edu.cn)的空教室查询网页。
输入教务处账号密码登录,即可按 **校区 / 教学楼 / 周次 / 星期 / 节次范围** 查询空闲教室。

**在线页面(GitHub Pages)**: https://zen1th-0.github.io/djtu-empty-classroom/

> Pages 只是前端界面。教务系统不允许浏览器跨域直连,登录与查询由本机后端代理完成,
> 所以使用在线页面时**仍需在自己电脑上运行 `node server.js`**(页面会自动连接 `http://127.0.0.1:8321`)。
> 后端地址可用 URL 参数覆盖:`?api=http://192.168.x.x:8321`。

## 访问方式

| 场景 | 做法 |
|---|---|
| 电脑 | 运行 `node server.js`,浏览器打开 `http://127.0.0.1:8321`(推荐,前后端同源最稳) |
| 手机(推荐) | 手机与电脑连同一 Wi-Fi,运行 `node server.js` 后按启动日志提示,手机浏览器访问 `http://电脑IP:8321` |
| GitHub Pages 入口 | 电脑运行 `node server.js` 后,打开 https://zen1th-0.github.io/djtu-empty-classroom/ |

## 运行

零 npm 依赖,只需 Node.js ≥ 18:

```bash
node server.js
# 打开 http://127.0.0.1:8321
```

端口/监听地址可用环境变量修改:`PORT=9000 HOST=127.0.0.1 node server.js`
(默认监听 `0.0.0.0` 以便手机局域网访问;仅本机使用可设 `HOST=127.0.0.1`)

## 使用流程

1. 打开网页,输入**学号、教务处密码**,填写**验证码**(点击图片可刷新)登录;
2. 登录后自动读取当前学期与周次(如"2026秋 第10周");
3. 选择校区、勾选教学楼(可多选)、周次、星期、空闲节次范围(全天/上午/下午/晚间快捷选择);
4. 点击"查询空教室",结果按楼栋分组显示,每间教室带 11 节占用格(绿=空闲,红=占用,蓝框=所选节次);
5. 默认只显示所选节次全程空闲的教室,可取消勾选查看全部;支持按教室名搜索(如 `2-301`)。

教室命名规则:**J##=教学楼,T##=图书馆语音室,Y##=研究生楼**。

## 实现原理(教务处接口)

| 步骤 | 接口 | 说明 |
|---|---|---|
| 会话 | `GET /academic/common/security/affairLogin.jsp` | 获取 JSESSIONID |
| 验证码 | `GET /academic/getCaptcha.do?captchaCheckCode=0` | 与会话绑定,返回 JPEG |
| 登录 | `GET /academic/j_acegi_security_check?j_username=&j_password=&j_captcha=` | 密码为**双重 MD5**(小写十六进制):`md5(hex(md5(密码)))`,与登录页 `md5.js` 中 `submit_hex_md5` 一致 |
| 会话校验 | `GET /academic/listLeft.do` | 验证登录态,解析学期(`2026秋`)与当前周次、星期 |
| 用户信息 | `GET /academic/showHeader.do` | 解析姓名;注意该页为 **UTF-8** 编码且校验 `Referer: index_frame.jsp` |
| 占用查询 | `POST /academic/teacher/teachresource/roomschedule_week.jsdo` | 参数 `aid`(校区)、`buildingid`、`whichweek`(周)、`week`(星期);一次返回**整栋楼**全部教室的 11 小节占用表(GBK 编码 HTML),占用格为红点 `●`,空闲为 `&nbsp;` |

校区/教学楼编号(来自"教室查询"模块,moduleId=1070):

- 沙河口校区 `aid=1`:1号楼(80)、2号楼(97)、3号楼(160)、4号楼(187)、5实验馆(224)、6图书馆(213)、7南区教学楼(282)、8南区实验楼(3302)、马克思学院楼(3201)等
- 旅顺口校区 `aid=78`:R2-R9号楼、R13号楼、教学楼(1061)、创新楼、研究生楼、图书馆等

## 项目结构


## 安全说明

- 教务处会话 Cookie 与登录态仅保存在本进程内存(30 分钟无操作自动清理),**不落盘**;
- 密码只在登录请求中使用一次,不做任何存储;
- 服务默认只监听 `127.0.0.1`,仅本机可访问;
- 验证码由用户人工识别,不做自动识别。

## 常见问题

- **登录失败/验证码错误**:验证码输错后页面会自动刷新验证码,重新输入即可;
- **登录已过期**:教务处会话约 30 分钟超时,重新登录即可;
- **查询结果为空**:确认该楼在该周/星期是否有排课数据(假期周可能无数据),或放宽节次范围。
